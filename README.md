# 埋地管道外腐蚀深度预测 —— v1 网页版（纯静态，可放 GitHub Pages）

## 这是什么
这是 v1 演示程序的**网页版**：打开网址就能用，**不用安装 Python、不用下载任何东西**。
它和 Windows 版（双击 run.bat 的那个）**用的是同一个已训练好的模型**：
- 没有重新训练，也没有改任何参数。`model.js` 里的数字是从 Windows 版的模型文件 `model/svr_pipeline.joblib` 原样导出的（标准化的均值和标准差、涂层 one-hot 顺序、SVR 的 186 个支持向量、权重、截距、gamma=0.091463…）。
- 浏览器里按和 scikit-learn 完全相同的公式计算：标准化 → one-hot → RBF 核 SVR → expm1 还原成毫米 → ± 区间半宽 1.0847 mm（下限不低于 0）。
- 核对结果：259 行数据逐行比对，网页版和 Python 原模型的最大差别是 **5.5×10⁻¹⁴ mm**，可以看作完全一样。
- 所有计算都在**用户自己的浏览器里**完成，填的数据和上传的 CSV **不会发到任何服务器**；网页不加载任何外部脚本、字体或 CDN。

页面内容与 Windows 版一致：① 单条输入（11 项，涂层下拉框，缺项提示）→ ② 单条结果（预测深度、80% 区间、灰色「待定（规则未定）」、预测深度 ≥ 4.76 mm 时显示红字「深坑样本少，模型可能低估，请结合实测复核」）；③ 批量排序（上传 CSV，按区间上限从高到低排序，导出带 BOM 的 CSV，Excel 打开中文不乱码）。

## 怎么用
- 打开网址（发布到 GitHub Pages 后的地址），按页面提示填写即可。
- 三个测试例子：首页逐项填写（数值见 Windows 版 README 第三节），或在「③ 批量排序」里先点链接下载 `sample_batch.csv`，再上传它。
  应看到：例子 1 = 1.0 mm（0.0–2.1）；例子 2 = 1.7 mm（0.6–2.8）；例子 3 = 12.1 mm（11.0–13.2，有红字）。
- 不联网时也能用：把整个文件夹拷到电脑上，双击 `index.html` 即可（模型参数写在 `model.js` 里，不需要服务器）。

## 文件说明
| 文件 | 作用 |
|---|---|
| `index.html` | 主页面（三个部分都在这一页，用导航切换） |
| `style.css` | 页面样式 |
| `config.js` | 固定设定：11 个特征、涂层 5 种、深坑红字触发值 `DEEP_PIT_WARNING_MM = 4.76`（项目方已确认；不是分级阈值） |
| `model.js` | 已训练模型的参数（自动导出，请勿手改） |
| `predictor.js` | 预测核心：输入检查、SVR 计算、80% 区间（不含分级） |
| `grading.js` | 风险分级预留位置：本版固定返回「待定（规则未定）」，内有 TODO |
| `app.js` | 页面逻辑：表单、页面切换、CSV 读取 / 排序 / 导出 |
| `sample_batch.csv` | 批量测试文件（3 个例子） |
| `.nojekyll` | 告诉 GitHub Pages 按原样发布文件（空文件） |
| `tools/export_model.py` | 开发者用：从 joblib 模型导出 model.js |
| `tools/verify_node.js` | 开发者用：在 node 里逐行比对 JS 与 Python 预测 |
| `tools/test_dom.js` | 开发者用：模拟浏览器测试页面（需要 jsdom） |

## 发布到 GitHub Pages（给负责账号的同学）
把本文件夹里的全部文件放到仓库根目录 → 仓库 Settings → Pages → Source 选 "Deploy from a branch"，分支选 main、目录选 `/ (root)` → 保存，几分钟后会给出网址。

## 精度口径（与 Windows 版相同，不变）
SVR 25 折 R²=0.556±0.205，RMSE=1.31 mm，MAE=0.76 mm（RF 0.527±0.187、HGB 0.439±0.223 仅作对照）。
注意：三个测试例子都在训练数据里，结果偏乐观；对模型没见过的深坑可能严重低估（详见 Windows 版 test_report.md）。
